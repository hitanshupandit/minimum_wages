# U.S. Minimum Wage Dashboard

Interactive dashboards tracking federal, state, city, and county minimum wages
across the United States — with a live California choropleth map, Census QWI
earnings integration, and verified rates for 58 local jurisdictions.

![License](https://img.shields.io/badge/data_license-CC_BY_4.0-green)
![Verified](https://img.shields.io/badge/rates_verified-Jan_2026-brightgreen)

## Dashboards

| File | Description |
|------|-------------|
| `dashboards/dashboard_with_map.html` | **Main dashboard** — US SVG map colored by wage tier, click-to-compare states, all-raisers trend chart, California 4-view deep dive, local wages table with sparklines |
| `dashboards/ca_minwage_map.html` | **California map** — 58-county choropleth, 39 city/county markers, animated year slider 2000–2025, fully self-contained |
| `dashboards/minwage_qwi_dashboard.html` | **Live QWI** — Census Bureau API, real earnings vs minimum wage, Kaitz Index, industry breakdown (free API key required) |
| `dashboards/minwage_acs_dashboard.html` | ACS poverty, median income, unemployment, rent burden crossed with wage data |
| `dashboards/minwage_gini_dashboard.html` | Gini coefficient, Lorenz curves, income quintile analysis |
| `dashboards/minwage_unified_dashboard.html` | Full combined dataset explorer with data lineage panel |

All dashboards are **self-contained HTML files** — open directly in a browser or host on GitHub Pages with no build step.

## Data sources

| Source | Coverage | License |
|--------|----------|---------|
| [Vaghul & Zipperer (2022) v1.4.0](https://github.com/benzipperer/historicalminwage) | Federal + state wages, 1938–2023 | CC BY 4.0 |

## Quick start

### 1. Clone and install

```bash
git clone https://github.com/YOUR_USERNAME/minwage-dashboard.git
cd minwage-dashboard
pip install -r requirements.txt
```

### 2. Run the full data pipeline

```bash
python scripts/run_pipeline.py
```

This fetches raw data from Zipperer's GitHub and (optionally) the UCB Excel,
processes everything into clean CSVs + chart-ready JSONs, and prints a
validation table. Individual steps:

```bash
python scripts/fetch_data.py              # download -> data/
python scripts/process_data.py            # process -> data/processed/
python scripts/process_data.py --state WA # also build WA deep-dive JSON
```

### 3. Serve locally

```bash
python -m http.server 8000
# open http://localhost:8000
# or directly: http://localhost:8000/dashboards/dashboard_with_map.html
```

### 4. UCB Excel (optional)

If the automatic UCB download fails:
1. Download manually from [laborcenter.berkeley.edu](https://laborcenter.berkeley.edu/minimum-wage-living-wage-resources/)
2. Save as `UCB-Labor-Center-City-and-County-Minimum-Wage-Inventory.xlsx` in the project root
3. Re-run `python scripts/fetch_data.py`

Or skip it entirely — all dashboards have verified data embedded:
```bash
python scripts/run_pipeline.py --skip-ucb
```

## Live QWI Dashboard

`dashboards/minwage_qwi_dashboard.html` calls the Census QWI API live. It needs a **free key**:

1. Sign up at [api.census.gov/data/key_signup.html](https://api.census.gov/data/key_signup.html)
2. Open the dashboard and paste the key in the top-right input box
3. Select a state, year, age group, and NAICS sector — data loads instantly

## Combined dataset

`data/us_minwage_combined.csv` — 121 rows × 97 columns:

| Field | Description |
|-------|-------------|
| `jurisdiction_id` | `US-FEDERAL`, `US-CA`, `LOCAL-CA-001`, … |
| `jurisdiction` | Name of the jurisdiction |
| `state` | State abbreviation |
| `level` | Federal / State / City / County |
| `source` | Zipperer or UCB Labor Center |
| `license` | CC BY 4.0 |
| `mw_1938` … `mw_2025` | Minimum wage by year |

Rebuild with:
```bash
python scripts/build_dataset.py
```
