Dashboards

Main dashboard

U.S. Minimum Wage Explorer

Interactive US map, state-by-state comparison panel, all-raisers historical trend, California deep-dive, and local ordinances table.

  • Clickable SVG US map colored by wage tier
  • Side-by-side state comparison with local ordinance bars
  • All 31 wage-raising states on one trend chart
  • California step-function chart with 4 views
  • 39 CA cities + 19 other localities with sparklines
Open dashboard → California map

California Choropleth Map

All 58 California counties colored by effective minimum wage, with animated city and county ordinance markers.

  • Year slider 2000–2025 with animate button
  • 39 city/county markers — circles for cities, squares for counties
  • Marker size and color encode premium above state floor
  • Sidebar shows active ordinances sorted by wage
  • 100% self-contained — no CDN or network required
Open CA map → Live QWI data

QWI Earnings Explorer

Live Census Bureau QWI API integration — real payroll earnings crossed with minimum wage series in real time.

  • Requires free Census API key (api.census.gov)
  • EarnS · EmpS · HirN · Sep · FrmJbGn / FrmJbLs
  • QWI-based Kaitz Index (min wage ÷ actual earnings)
  • Filter by state, year, age group, NAICS sector
  • Industry breakdown + hiring vs separations chart

Quick start

Run the data pipeline locally to fetch and process the latest wage data.

# 1. Install dependencies
pip install -r requirements.txt

# 2. Fetch + process in one command
python run_pipeline.py

# 3. Serve locally (needed for CSV loading)
python -m http.server 8000
# then open http://localhost:8000
# Deploy to GitHub Pages
git add .
git commit -m "Update minimum wage data"
git push

# Enable Pages: Settings → Pages → Deploy from branch → main
# Dashboard live at: https://YOUR_USERNAME.github.io/minwage-dashboard/
